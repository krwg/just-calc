# JustCalc

A small desktop calculator built with Python and Tkinter.


## Features

- Basic arithmetic (`+`, `-`, `*`, `/`)
- Themes: Light, Dark, Moon
- Calculation history
- Decimal precision settings
- Keyboard input
- Safe expression evaluation (no bare `eval`)

## Requirements

- Python 3.9+
- Tkinter (usually bundled with Python)

## Run

```bash
python3 justcalc.py
```

## Tests

```bash
python3 -m unittest discover -s tests -v
```
